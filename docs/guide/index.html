가이드

보컬 레슨용 도구 3가지(음정 분석기 · 연습 플레이어 · MR Studio)를 쓰는 방법이에요. 선생님은 1~2번만 읽어도 바로 쓸 수 있어요.

1. 시작하기2. 음정 분석기3. 연습 플레이어4. 레슨 활용5. 문제 해결6. 보내는 사람용

1. 시작하기 (iPhone)

  1. Safari로 받은 링크를 열어요. (LINE·카카오톡 앱 안의 브라우저에서는 마이크가 막힐 수 있어요. 오른쪽 아래 “Safari에서 열기”)
  2. 공유 버튼(□↑) → 홈 화면에 추가. 이후엔 앱처럼 아이콘으로 열려요.
  3. 처음 마이크를 켤 때 나오는 허용을 눌러요. (실수로 거부했다면 5번 문제 해결 참고)
  4. 이어폰을 꽂으면 반주와 목소리가 섞이지 않아 더 정확해요.
음성은 모두 기기 안에서만 처리되고 서버로 전송되지 않아요. 회원가입도 필요 없어요.

2. 음정 분석기

화면 보는 법

  • 큰 글자: 지금 내는 음(예: A3)과 기준음에서 얼마나 벗어났는지(센트, 100센트 = 반음). ±10센트 안이면 거의 정확해요.
  • 스펙트럼/그래프: 목소리 높낮이의 흐름. 막대가 안정적일수록 음정이 흔들리지 않아요.
  • 음역 기록: 낸 가장 낮은 음~가장 높은 음을 기억해요. 학생의 음역 파악에 좋아요.
  • 반응이 약하면 감도 슬라이더를 올려요(작은 소리까지 인식).

판정 모드 (남·녀 함께 쓸 때)

  • 목표 음을 정하면 실시간으로 PERFECT / GREAT / GOOD / MISS를 판정해요.
  • 옥타브 무관를 켜면 한 옥타브 위/아래로 불러도 같은 음으로 인정해요. 남녀가 같은 멜로디를 각자의 음역으로 부를 때 유용해요.
  • 프리셋은 여성/남성 그룹으로 나뉘어 있어요. 학생 목소리에 맞는 것을 골라요.

3. 연습 플레이어

  1. 음원 열기: 파일 앱, iCloud Drive, 음성 메모, AirDrop으로 받은 파일 등에서 mp3 / m4a / wav를 골라요.
  2. 키: − / ＋ 로 반음 단위(±12)로 바꿔요. 원곡이 너무 높거나 낮을 때, 학생에게 맞는 키를 찾을 때 써요.
  3. 템포: 50~130%. 키는 그대로 두고 속도만 바뀌어요. 어려운 부분은 70%로 천천히.
  4. A–B 반복: 재생하다가 시작 지점에서 [A], 끝 지점에서 [B]를 누르면 그 구간을 계속 반복해요. ±0.5초 버튼으로 미세 조정, 파형을 눌러서 위치 이동도 돼요.
반주(MR)가 필요하면 PC의 MR Studio로 곡에서 보컬을 지운 파일을 만들어 보내면 돼요. 키·템포·구간도 미리 정해서 만들 수 있어요.

4. 레슨 활용 아이디어

  • 음역 체크: 분석기로 학생이 편하게 내는 가장 낮은 음~높은 음을 기록 → 연습 곡의 키를 정해요.
  • 키 맞추기: 플레이어에서 반음씩 바꿔 가며 학생이 가장 편한 키를 찾아요.
  • 느리게 → 원속: 어려운 프레이즈를 70% → 85% → 100%로 올려가며 A–B 반복.
  • 음정 시각화: 같은 구절을 부르게 하고 분석기 화면을 같이 보며 어디서 흔들리는지 확인해요.
  • 게임처럼: 판정 모드로 “GREAT 이상 5번 연속”처럼 목표를 정해요.

5. 문제 해결

마이크가 반응하지 않아요

  • LINE 등 앱 안의 브라우저가 아니라 Safari인지 확인해요.
  • iPhone 설정 → Safari → 마이크가 “허용” 또는 “확인”인지, 해당 사이트가 거부되어 있지 않은지 확인해요.
  • 분석기의 감도 슬라이더를 올려요. 조용한 곳에서 입을 마이크에 가까이.

소리가 안 나요

  • 옆면의 무음 스위치(벨 모양)와 음량을 확인해요.
  • 화면을 한 번 눌러 재생을 시작해요(iPhone은 터치 후에만 소리가 나요).

파일이 열리지 않아요

  • mp3 / m4a / wav로 시도해요. 아주 긴 파일(10분 이상)은 메모리 때문에 열리지 않을 수 있어요.
저작권이 있는 음원은 개인 연습용으로만 사용해 주세요.

6. 보내는 사람용 (메시지 예시)

아래 문장을 그대로 LINE이나 메일로 보내면 돼요. 링크는 이 키트의 첫 화면 주소예요.

ガイド

ボーカルレッスン用の3つのツール(音程アナライザー・練習プレーヤー・MR Studio)の使い方です。先生は1〜2だけ読めばすぐ使えます。

1. 使い始め2. 音程アナライザー3. 練習プレーヤー4. レッスン活用5. 困ったとき6. 送る人向け

1. 使い始め(iPhone)

  1. 届いたリンクをSafariで開きます。(LINEなどアプリ内ブラウザではマイクが使えないことがあります。右下の「Safariで開く」から)
  2. 共有ボタン(□↑)→ ホーム画面に追加。次からはアプリのようにアイコンで開けます。
  3. 初めてマイクを使うときに出る許可を押します。(誤って拒否した場合は5の「困ったとき」へ)
  4. イヤホンを使うと、伴奏と声が混ざらず、より正確に測れます。
音声はすべて端末の中だけで処理され、サーバーには送られません。会員登録も不要です。

2. 音程アナライザー

画面の見かた

  • 大きな文字:今出している音(例:A3)と、基準の音からのずれ(セント。100セント=半音)。±10セント以内ならほぼ正確です。
  • スペクトラム/グラフ:声の高さの流れ。安定しているほど音程が揺れていません。
  • 音域の記録:出せた最低音〜最高音を覚えてくれます。生徒さんの音域把握に便利です。
  • 反応が弱いときは感度スライダーを上げます(小さな声まで拾います)。

判定モード(男女いっしょのとき)

  • 目標の音を決めると、リアルタイムで PERFECT / GREAT / GOOD / MISS を判定します。
  • オクターブ無関係をオンにすると、1オクターブ上・下で歌っても同じ音として認めます。男女が同じ旋律をそれぞれの音域で歌うときに便利です。
  • プリセットは女性/男性のグループに分かれています。生徒さんの声に合うものを選びます。

3. 練習プレーヤー

  1. 音源を開く:ファイルApp、iCloud Drive、ボイスメモ、AirDropで受け取ったファイルなどから mp3 / m4a / wav を選びます。
  2. キー:− / ＋ で半音ずつ(±12)変えます。原曲が高すぎ・低すぎるとき、生徒さんに合うキーを探すときに使います。
  3. テンポ:50〜130%。キーはそのままで速度だけ変わります。難しい所は70%でゆっくり。
  4. A–Bリピート:再生しながら始めたい所で[A]、終わりたい所で[B]を押すと、その区間を繰り返します。±0.5秒ボタンで微調整、波形をタップして位置を動かすこともできます。
伴奏(カラオケ音源)が必要なときは、PCのMR Studioで曲からボーカルを消したファイルを作って送れます。キー・テンポ・区間も先に決めて作れます。

4. レッスンでの活用アイデア

  • 音域チェック:アナライザーで、生徒さんが楽に出せる最低音〜最高音を記録 → 練習曲のキーを決めます。
  • キー合わせ:プレーヤーで半音ずつ変えて、いちばん楽なキーを探します。
  • ゆっくり → 原速:難しいフレーズを70% → 85% → 100%と上げながらA–Bリピート。
  • 音程の見える化:同じフレーズを歌ってもらい、アナライザーの画面を一緒に見て、どこで揺れるかを確認します。
  • ゲーム感覚:判定モードで「GREAT以上を5回連続」のような目標を作ります。

5. 困ったとき

マイクが反応しません

  • LINEなどのアプリ内ブラウザではなくSafariで開いているか確認します。
  • iPhoneの設定 → Safari → マイクが「許可」または「確認」か、このサイトが拒否になっていないか確認します。
  • アナライザーの感度スライダーを上げ、静かな場所でマイクに近づいて声を出します。

音が出ません

  • 側面のサイレントスイッチ(ベルのマーク)と音量を確認します。
  • 画面を一度タップして再生を始めます(iPhoneはタップの後でないと音が出ません)。

ファイルが開けません

  • mp3 / m4a / wav でお試しください。とても長いファイル(10分以上)はメモリの都合で開けないことがあります。
著作権のある音源は、個人の練習用だけにお使いください。

Guide

How to use the three tools for vocal lessons: pitch analyzer, practice player and MR Studio. A teacher only needs sections 1 and 2 to get going.

1. Getting started2. Pitch analyzer3. Practice player4. Lesson ideas5. Troubleshooting6. For the sender

1. Getting started (iPhone)

  1. Open the link in Safari. (In-app browsers such as LINE can block the microphone — use “Open in Safari”.)
  2. Tap Share (□↑) → Add to Home Screen. It will then open like an app.
  3. When the microphone is first requested, tap Allow. (If you denied it by mistake, see Troubleshooting.)
  4. Earphones keep the backing track out of the mic, which makes the readings more accurate.
Audio is processed only on your device and is never sent to a server. No sign-up needed.

2. Pitch analyzer

Reading the screen

  • Big text: the note you are singing (e.g. A3) and how far it is from the reference (cents; 100 cents = one semitone). Within ±10 cents is nearly spot on.
  • Spectrum / graph: the flow of your pitch. A steadier line means steadier intonation.
  • Range: remembers the lowest and highest notes you hit — handy for finding a student's range.
  • If it reacts weakly, raise the sensitivity slider to pick up quieter sounds.

Judge mode (mixed male and female voices)

  • Pick a target note and it grades you live: PERFECT / GREAT / GOOD / MISS.
  • Turn on octave-agnostic so singing an octave higher or lower still counts. Useful when men and women sing the same melody in their own ranges.
  • Presets are grouped into Female and Male. Choose the one that suits the student.

3. Practice player

  1. Open audio: pick an mp3 / m4a / wav from Files, iCloud Drive, Voice Memos or a file received via AirDrop.
  2. Key: − / ＋ changes it in semitones (±12). Use it when the original is too high or low, or to find a student's comfortable key.
  3. Tempo: 50–130%. Only the speed changes, not the key. Take hard passages at 70%.
  4. A–B loop: while playing, tap [A] at the start and [B] at the end and that section repeats. Fine-tune with the ±0.5 s buttons, or tap the waveform to jump.
Need a backing track? Use MR Studio on a PC to remove the vocals from a song and send the file. Key, tempo and section can be set beforehand.

4. Lesson ideas

  • Range check: record the lowest and highest notes a student sings comfortably, then choose the key of the practice song.
  • Find the key: shift the player a semitone at a time to find the most comfortable key.
  • Slow → full speed: loop a hard phrase at 70% → 85% → 100%.
  • See the pitch: have the student sing a phrase and watch the analyzer together to spot where it wavers.
  • Make it a game: set goals in judge mode, such as “five GREAT or better in a row”.

5. Troubleshooting

The microphone does not respond

  • Check that you are in Safari, not an in-app browser such as LINE.
  • On iPhone, open Settings → Safari → Microphone and make sure it is Allow or Ask, and that this site is not denied.
  • Raise the sensitivity slider and sing close to the mic in a quiet place.

No sound

  • Check the silent switch (bell icon) on the side and the volume.
  • Tap the screen once to start playback — iPhone only plays sound after a tap.

A file will not open

  • Try mp3 / m4a / wav. Very long files (10 min or more) may not open because of memory.
